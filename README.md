# School Management Portal

- Built a role-based School Management System using Django.
- Implemented teacher and student authentication.
- Developed attendance, marks, assignments, announcements and report-card modules.
- Designed responsive UI using HTML, CSS and JavaScript.
- Integrated Django ORM with SQLite database.
- Deployed the application on Render and managed source code with GitHub.

A full-stack Django web application for managing:

- Student Registration
- Teacher Login
- Attendance Management
- Marks Management
- Assignments
- Announcements
- Report Cards
- Role-Based Authentication

Tech Stack:
- Django
- SQLite
- HTML
- CSS
- JavaScript
